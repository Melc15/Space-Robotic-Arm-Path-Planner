# Space-Robotic-Arm-Path-Planner

This project uses public data for the robot manipulator arm model for the Space Station Remote Manipulator System (SRMS) or Canadarm2.

The data was accessed through https://github.com/vyas-shubham/TraceableRobotModels/tree/master/SSRMS_Canadarm2?utm_source=chatgpt.com.

The original publication:

Nguyen, Phung Khac, and Peter C. Hughes. "Teleoperation: from the space shuttle to the space station." Progress in astronautics and aeronautics 161 (1994): 353-353.
